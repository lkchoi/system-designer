# System Designer

An interactive system architecture designer built with React, TypeScript, and [React Flow](https://reactflow.dev). Design distributed systems on a visual canvas, configure technologies, simulate failures, and export to infrastructure-as-code.

## Features

- **18 component types** — databases, services, caches, queues, load balancers, CDNs, and more ([reference](docs/components.md))
- **12 architectural patterns** — Cache-Aside, CQRS, Pub/Sub Fanout, and more as drag-and-drop subgraphs ([catalog](docs/patterns.md))
- **11 export formats** — Docker Compose, Terraform, CloudFormation, Kubernetes, AWS CDK, Pulumi, Nomad, OpenAPI, and more ([guide](docs/export-formats.md))
- **14 tools** — Capacity Calculator, Cron Translator, SLA Calculator, Cache Sizer, and more ([reference](docs/tools.md))
- **4 modes** — Plan (configure tech), Stress (simulate failures), Monitor (health metrics), Price (cost analysis)
- **Connection validation** — enforces architectural constraints at both component and technology level
- **Code generation** — Docker Compose export scaffolds Go, Node.js, or Python services with SDK imports, health checks, and tests
- **No backend** — all data in browser SQLite via OPFS. No account, no server, no data leaves your browser.

## Quick start

```bash
bun install
bun run dev          # https://localhost:5173
```

## Develop

### Prerequisites

- [Bun](https://bun.sh/)
- [mkcert](https://github.com/FiloSottile/mkcert) for local HTTPS

### Setup

```bash
bun install

# Install mkcert's local CA into your system trust store (one-time)
mkcert -install

# Generate certificates for localhost
mkdir -p .certs
mkcert -key-file .certs/key.pem -cert-file .certs/cert.pem localhost 127.0.0.1 ::1
```

### Run

```bash
bun run dev
```

The dev server starts at `https://localhost:5173` with a trusted certificate.

### Test

```bash
bun run test          # single run
bun run test:watch    # watch mode
bunx tsc --noEmit     # type check
```

### Build and deploy

```bash
bun run build         # tsc + vite build
bun run deploy        # deploy to Cloudflare Pages
```

## Tech stack

React 19, TypeScript 6, React Flow, Tailwind CSS 4, sql.js + OPFS, Vite 8, Vitest, Cloudflare Pages.

## Pricing data

Technology pricing for 86 services is maintained in `src/registry/pricing.ts`, generated by modular fetch scripts under `scripts/pricing/`.

```bash
bun run pricing:fetch                              # run all fetchers
bun run pricing:list                               # list fetchers and counts
bunx tsx scripts/pricing/run.ts --only aws,azure   # run specific fetchers
bunx tsx scripts/pricing/run.ts --dry-run           # fetch without overwriting
```
